油管下载器便携版

开始使用
1. 将 ZIP 完整解压到一个可写文件夹，不要直接在压缩包内双击程序。
2. 双击“油管下载器.exe”。请保留旁边的 tools 和 licenses 文件夹。
3. 粘贴 YouTube 链接，多条链接每行一条。
4. 选择保存位置和清晰度，点击开始下载。
5. 默认保存到程序旁边的 Downloads；完成后可从窗口打开保存文件夹。

下载与取消
- 默认优先下载并合并为 MP4，视频与音频可能分开下载。单个下载进度到 100%
  后，仍可能需要下载另一条流或合并，请以程序的最终状态为准。
- “最好”使用网站提供的可用清晰度；选择 1080p、720p 等表示分辨率上限，
  不会把低清视频放大为高清。
- 播放列表默认关闭。只有需要下载整个列表时才勾选对应选项。
- 取消会停止当前任务及其子进程。已完成文件会保留，未完成的 .part 等文件
  也可能保留；再次使用相同链接和保存目录可尝试断点续传。
- 已存在的完整文件不会被覆盖。移动或删除临时分段后，续传可能需要重来。
- 多条任务中部分失败时，请查看窗口日志中的错误和最终汇总，再单独重试失败链接。

网络与限制
- 需要能访问 YouTube 的网络。代理为可选项，留空按工具当前环境处理；
  如需指定，可填 http://127.0.0.1:端口 或 socks5://127.0.0.1:端口。
- 代理地址只用于本次下载，不会修改 Windows 系统代理。
- 私有、登录限定、地区限制、付费或被网站拒绝的链接可能无法下载。
  本程序不会读取浏览器登录信息，也不提供 Cookies 导入。
- 网站规则可能变化；若报“视频不可用”、验证要求或提取失败，先核对链接、
  网络及日志。无需反复点击开始。
- MP4 是容器格式，不代表所有系统播放器都支持其中的视频编码；如出现
  有声音无画面，可使用支持对应编码的播放器。

运行环境
- Windows 10 / 11，64 位，已启用 .NET Framework 4.8 或更高兼容版本。
- 下载工具、FFmpeg、ffprobe 和 Node 已随包附带，不需要另装 Python、Node、
  PowerShell 7，也不需要修改 PATH。首次启动不自动下载运行环境。
- 下载目录需要可写权限和足够空间；高分辨率视频合并期间会占用额外临时空间。
- 不建议放在 Windows、Program Files 等普通用户不可写的系统目录。
- 程序未使用商业代码签名证书；请从可信来源获取，并核对发布方提供的 SHA-256。

随包文件
- 油管下载器.exe：图形窗口。
- tools：独立下载与音视频处理工具，不要单独移动或重命名。
- Downloads：默认保存目录（初始为空）。
- THIRD-PARTY-NOTICES.txt、VERSIONS-AND-SOURCES.txt、licenses：
  第三方组件版本、来源、许可及相关通知。
- CHECKSUMS.sha256：本次构建发行文件的 SHA-256 清单。
